# Análise Comparativa: Dólar em Anos Eleitorais (2014-2026)

Este projeto utiliza **Python** e a biblioteca `yfinance` para analisar o comportamento do par **USD/BRL** em anos de eleições presidenciais no Brasil.

## 📈 Contexto da Análise
Em abril de 2026, o dólar atingiu patamares próximos a **R$ 5,14**, sendo considerado "barato" em relação aos fundamentos fiscais de longo prazo. Esta análise busca identificar se existe um padrão de valorização da moeda americana no segundo semestre de anos eleitorais.

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Pandas**: Manipulação de dados.
- **Matplotlib**: Visualização de dados.
- **Yahoo Finance API**: Extração de cotações históricas.

## 🚀 Como executar
1. Crie um ambiente virtual: `python -m venv venv`
2. Ative o venv: `.\venv\Scripts\activate`
3. Instale as dependências: `pip install yfinance pandas matplotlib`
4. Execute: `python main.py`

## 🧐 Conclusões Preliminares
Historicamente, o período entre agosto e outubro apresenta maior volatilidade devido à definição do cenário político. O patamar atual de 2026 pode representar uma janela de oportunidade para diversificação internacional (ETFs e Bonds), dada a assimetria de risco para o final do ano.
